# Development

Python 3.12 and [uv](https://docs.astral.sh/uv/).

```bash
uv sync --locked --extra cpu
uv run ruff check .
uv run ruff format --check .
uv run mypy
uv run pytest -m "not slow and not network and not data"
uv run tsfm pipeline --config configs/tiny_cpu.yaml
uv run tsfm docs build
uv run tsfm docs check
```

The pipeline needs a network connection. It writes to a temporary directory, outside `results/`.

## Generated documents

Edit `docs_templates/*.md`, then run `uv run tsfm docs build`. These files are outputs:

* `README.md`, `DATA_CARD.md`, `MODEL_CARD.md`, `RESEARCH_NOTE.md`
* `docs/figures/hero.svg`, `docs/figures/architecture.svg`, `docs/figures/integrity.svg`, `docs/figures/coverage.svg`, and `docs/figures/scaling.svg`

`uv run tsfm docs check` fails if any of them drift, and if a generated document shows a number that is not in `results/` or `docs_templates/allowed_numbers.txt`. Placeholders are not allowed inside code fences, so a diagram cannot smuggle a measured value past the check.

## Frozen records

Do not hand-edit these. If a tool is allowed to rewrite one, run that tool and commit its output.

* `results/**`
* `locks/**`
* `PREREGISTRATION.md`, `PREREGISTRATION_CPU.md`, `PREREGISTRATION_VOL.md`
* `DEVIATIONS.md`

## Notebooks

`notebooks/*.ipynb` are generated by `python3 scripts/make_colab_notebook.py`. The remaining test-split score is `notebooks/score_patch_s2_test.ipynb` on a Colab T4. The README has the steps. `notebooks/colab_runner.ipynb` is the historical training queue and does not start until its confirm flag is set.
