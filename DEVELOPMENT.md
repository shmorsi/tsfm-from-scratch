# Development

Python 3.12 and [uv](https://docs.astral.sh/uv/).

```bash
uv sync --locked --extra cpu
uv run ruff check .
uv run ruff format --check .
uv run mypy
uv run pytest -m "not slow and not network and not data"
uv run tsfm pipeline --config configs/tiny_cpu.yaml
uv run tsfm docs build
uv run tsfm docs check
```

The pipeline needs a network connection. It writes to a temporary directory, outside `results/`.

## Generated documents

Edit `docs_templates/*.md`, then run `uv run tsfm docs build`. These files are outputs:

* `README.md`, `DATA_CARD.md`, `MODEL_CARD.md`, `RESEARCH_NOTE.md`
* `docs/figures/hero.svg`, `docs/figures/architecture.svg`, `docs/figures/integrity.svg`, `docs/figures/coverage.svg`, and `docs/figures/scaling.svg`

`uv run tsfm docs check` fails if any of them drift. The unit tests (`tests/test_docs_numbers.py`) fail if a generated document shows a number that is not in `results/` or `docs_templates/allowed_numbers.txt`. Placeholders are not allowed inside code fences, so a diagram cannot smuggle a measured value past that guard.

## Frozen records

Do not hand-edit these. If a tool is allowed to rewrite one, run that tool and commit its output.

* `results/**`
* `locks/**`
* `PREREGISTRATION.md`, `PREREGISTRATION_CPU.md`, `PREREGISTRATION_VOL.md`
* `DEVIATIONS.md`

## Notebooks

`notebooks/*.ipynb` are generated by `python3 scripts/make_colab_notebook.py`.

* `notebooks/score_patch_s2_test.ipynb` produced the one test-split score of `patch_s2` (`DEVIATIONS.md`, 2026-10-23). It is kept as the record of that run; `tsfm eval` refuses a second score.
* `notebooks/vol_study_patch_s2.ipynb` runs the pre-registered volatility study for the same checkpoint, zero-shot and fine-tuned, once. It writes `harvest_vol_patch_s2.txt` to Drive; `uv run python scripts/harvest_colab_output.py harvest_vol_patch_s2.txt` copies the results into the repository, and `uv run tsfm docs build` then shows them.
* `notebooks/colab_runner.ipynb` is the historical training queue and does not start until its confirm flag is set.

## Scaling configs

`configs/scaling/*.yaml` are generated by `uv run python scripts/make_scaling_configs.py`.
