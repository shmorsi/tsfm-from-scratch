# tsfm: a small time-series foundation model, trained from scratch

**Question.** How far does a small decoder-only transformer get on the GIFT-Eval zero-shot
benchmark when it is pretrained from scratch on a public, leakage-checked corpus plus
synthetic series, compared with classical baselines and a published model of similar size?

## Method in brief

* **Data.** A pinned subset of GiftEvalPretrain (every raw file SHA-256-checked), split
  into univariate series, capped per dataset, plus Gaussian-process kernel-mixture
  series. Ten whole datasets are held out for validation. A content-based leakage check
  compares every training series against every GIFT-Eval series.
* **Model.** Decoder-only transformer (pre-norm RMSNorm, RoPE, SwiGLU, KV cache) in plain
  PyTorch, with two tokenizers: patches with a non-crossing quantile head, and
  mean-scaled 4,096-bin quantisation with cross-entropy.
* **Evaluation.** The 97 official GIFT-Eval configurations, scored with GluonTS exactly as
  upstream does: MASE and the quantile-loss "CRPS", each normalised by Seasonal Naive,
  geometric mean over configurations; plus 50/80/90% interval coverage.

## Reproduce

```bash
uv sync --extra cpu
uv run pytest
uv run tsfm pipeline --config configs/tiny_cpu.yaml   # whole pipeline, small, on CPU
uv run tsfm data all                                  # full corpus (~16 GB download)
uv run tsfm pack
uv run tsfm eval --model seasonal_naive --split test
uv run tsfm report --split test
uv run tsfm docs build
```

GPU training runs on Google Colab with `notebooks/colab_runner.ipynb` (resumes exactly
from Drive checkpoints); `scripts/sync_results.py` copies results back with hashes.

## Limits

See the "not established" section of `RESEARCH_NOTE.md` once written. Known now:
the leakage check finds exact and affine copies only; the patch model's long-horizon
roll-out feeds back medians, which likely makes far-horizon intervals too narrow; and the
largest planned model sizes would repeat the pretraining data many times.
