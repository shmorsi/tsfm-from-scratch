# tsfm: a small time-series foundation model, trained from scratch

**Question.** How far does a small decoder-only transformer get on the GIFT-Eval zero-shot
benchmark when it is pretrained from scratch on a public, leakage-checked corpus plus
synthetic series, compared with classical baselines and published foundation models?

**What is here.** The model, both tokenizers, the training loop and sampling are written
by hand in plain PyTorch. The pretraining corpus is pinned by SHA-256 and audited for
overlap with the benchmark (the audit found real copies, all removed). The evaluation
reproduces upstream GIFT-Eval exactly, and the test comparison is fixed in a git tag.

Everything on this page is generated by `tsfm docs build` from files committed under
`results/`. A test fails if this page contains a number that is not in those files.

## Scope

The study ran on a free Colab T4 GPU within a fixed deadline. `DEVIATIONS.md` lists, before
any test scoring, what was cut from the pre-registered plan: the grid has three sizes
(`patch_s0` to `patch_s2`), the bins tokenizer was trained but not scored, and the headline
is a single seed, and the test-split scoring of our model was not completed, so no
test-set result is claimed for it. Everything reported was run as described.

## Method in brief

* **Data.** A pinned subset of GiftEvalPretrain (every raw file SHA-256-checked), split
  into univariate series, capped per dataset, plus Gaussian-process kernel-mixture
  series. Whole datasets are held out for validation. A content-based leakage check
  compares every training series against every GIFT-Eval series (`DATA_CARD.md`).
* **Model.** Decoder-only transformer (pre-norm RMSNorm, RoPE, SwiGLU, KV cache) in plain
  PyTorch; patches of 32 steps with a non-crossing quantile head (`MODEL_CARD.md`).
* **Training.** Mixed precision, gradient accumulation, cosine schedule, exact resume from
  checkpoints written to Google Drive every 10 minutes.
* **Evaluation.** The 97 official GIFT-Eval configurations, scored with GluonTS exactly as
  upstream does: MASE and the quantile-loss "CRPS", each normalised by Seasonal Naive,
  geometric mean over configurations; plus 50/80/90% interval coverage. Our Seasonal
  Naive equals upstream's on every official metric.

## Reproduce

```bash
uv sync --extra cpu
uv run pytest
uv run tsfm pipeline --config configs/tiny_cpu.yaml   # whole pipeline, small, on CPU
uv run tsfm data all                                  # full corpus (~16 GB download)
uv run tsfm pack
uv run tsfm eval --model seasonal_naive --split test
uv run tsfm report --split test
uv run tsfm docs build
```

GPU training and scoring run on Google Colab with `notebooks/colab_runner.ipynb` (resumes
exactly from Drive checkpoints). `COMMIT_MAP.md` maps commit hashes recorded in older
result files to the current history.

## Limits

See "Not established" in `RESEARCH_NOTE.md`. In short: no test-set result for our model
yet; one seed, three sizes; the leakage
check finds exact and affine copies only; the long-horizon roll-out feeds back medians,
which makes far-horizon intervals too narrow; nothing here measures economic value.
